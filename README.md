# 증강 체스

카드를 뽑아 기물에 능력을 더하는 **체스 변형 게임**이에요. 브라우저에서 바로 열어서 쓰는 웹 게임이고, 설치할 것이 없어요.

- 플레이: https://ssook0204-prog.github.io/augment-chess/
- 테스트 버전(미리 써 보기): https://ssook0204-prog.github.io/augment-chess/test.html

> 이 게임은 비공식 팬 프로젝트예요. augmentchess.org와는 관련이 없고, 같은 아이디어(카드 드래프트와 킹 잡기 승리)에서 영감을 받아 새로 만들었어요.

## 게임 규칙

- 보통 체스처럼 시작하지만, 정해진 수마다 **카드를 뽑아** 기물에 새 능력을 줘요.
- 이긴 쪽은 **상대 킹을 잡는 쪽**이에요. 체크메이트가 아니라 킹을 실제로 잡아야 끝나요.
- 카드 종류는 게임 안 **백과사전**에서 볼 수 있어요.

## 모드

| 구분 | 내용 |
| --- | --- |
| 일반 / 카오스 | 게임 방식을 고르는 모드 |
| 드래프트 | 원본(시작·10·20수에 3장), 확장(5수마다 10장) |
| 그랜드 | 드래프트 없이, 시작할 때 카드 24장 중 흑부터 번갈아 6장씩 고르기(END 카드는 3수 뒤부터, 시작 RULE 확률은 절반) |
| AI와 플레이 | 색을 골라 AI와 대국 |
| 2인 플레이 | 한 화면에서 번갈아 두기 |
| 멀티플레이 | 온라인에서 무작위 상대 찾기(상대가 없으면 AI) |
| 랭크전 | 점수(레이팅)를 걸고 대국하고 순위가 매겨져요 |
| 친선전 | 방을 만들거나 방 코드로 입장 |

- **AI 강화**: 메뉴의 "AI 강화"에서 오버클럭, 여제, 전장의 안개, 더 나은 선택, 추가 병사, 암살 전문가, 성전, 매너, 대규모 카드 지원, 나·주사위 선언 중 원하는 것을 AI에게 줄 수 있어요.
- **AI 레이팅**: AI와 플레이할 때 400~2400 사이로 AI 실력을 고를 수 있어요. 낮으면 실수가 잦고 수를 덜 읽어요. "자동 조절"을 켜면 이길 때 +100, 질 때 −100씩 바뀌어요.
- **경기 분석**: AI·2인 대국이 끝나면 수마다 평가(천재적인 수, 최선의 수, 실수, 큰 실수 등), 정확도, 형세 그래프를 볼 수 있어요. 기물 가치 기준의 간단한 분석이에요.
- **카드 표시**: 설정의 "카드 표시"에서 카드를 "그림"(판 위에 효과를 그림으로 보여 줘요, 기본)이나 "효과"(적용되는 효과를 글로 크게 보여 줘요) 중 골라 볼 수 있어요.

## 로그인과 닉네임

- **디스코드 로그인**: 점수와 닉네임이 서버에 저장되고, 어느 기기에서든 이어져요. 공용 순위표에 올라가요.
- **이메일 로그인**: 디스코드 없이도 서버에 저장되는 계정을 만들 수 있어요.
- **이 기기 계정**: 서버 없이 브라우저에만 저장돼요. "계정 코드 내보내기"로 다른 기기로 옮길 수 있어요.
- **게스트 모드**: 로그인 없이 `게스트1234` 같은 임시 닉네임으로 바로 시작해요. 점수는 이 브라우저에만 저장돼요.
- 닉네임은 겹칠 수 없고, "관리자" 같은 사칭용 이름은 쓸 수 없어요.
- 한 번 로그인하면 계속 유지돼요(자동 로그인).

## 관리자 기능

비밀이에요 대신 재 계정을 해킹 한다면 알수 있을겁니다.

## 테스트 버전

자동 업데이트는 없어요. 새 버전은 페이지를 새로고침하면 열려요. 새 기능은 먼저 테스트 버전(`test.html`)에 올라오고, 이전 버전은 설정에서 열 수 있어요.

## 어떻게 만들어졌나요

- 게임 전체가 **HTML 파일 하나**(`index.html`)에 들어 있어요. 빌드된 결과물이라 코드를 읽기보다는 열어서 쓰는 용도예요.
- 온라인 대전은 **PeerJS**(브라우저끼리 직접 연결)로 해요.
- 로그인, 닉네임, 점수, 순위표, 관리자 설정은 **Supabase**에 저장돼요.
- 호스팅은 **GitHub Pages**예요.

## 만든 사람

이 프로젝트는 **Anthropic의 AI Claude(Claude Code)**가 만들었어요. 프로젝트 주인(`게발자`)가 원하는 규칙과 기능을 말하면, Claude가 코드를 쓰고 테스트하고 배포까지 함께 진행했어요. 게임 규칙과 방향은 주인이 정했고, 코드와 문서는 Claude가 작성했어요.

사람이 직접 확인하지 못한 부분에 버그가 있을 수 있어요. 문제를 발견하면 이슈로 알려 주세요.
